# Distributed System Simulator (Lamport Mutex Simulator)

A simple multithreaded distributed system simulator written in Common Lisp to demonstrate Lamport's mutual exclusion algorithm [1]. Each node runs in its own thread, communicates by sending messages through a simulated network, and maintains a Lamport logical clock to synchronize access to a shared resource.

---

## Features

* **Thread-per-Node Execution**: Uses `bordeaux-threads` so each node runs independently in its own thread.
* **Lamport Logical Clocks**: Tracks logical time across nodes to establish event ordering.
* **Mutual Exclusion**: Implements the classic algorithm by Leslie Lamport to prevent data races on a shared resource without centralized control.
* **Simple Scripting**: A `node-program` macro makes it easy to write what each node should do.
* **Configurable Setup**: Supports point-to-point messages, broadcasts, and delays between node starts.

---

## Project Structure

* `distributed-system-sim.lisp`: Base simulator code defining nodes, networks, message passing, and thread lifecycles.
* `mutex-lamport.lisp`: Adds the `lamport-node` class, clock handling, message queues, and lock acquisition/release methods.
* `helpers.lisp`: Helper functions to initialize batches of nodes, join threads (`wait-for-all`), and control execution (`until`).
* `load.lisp`: Small script to pull in dependencies and compile the core files in order.
* `demo.lisp`: Step-by-step examples demonstrating basic communication, delayed start behavior, and resource contention with and without synchronization.

---

## Requirements

* A standard **Common Lisp** implementation (such as LispWorks).
* **ASDF**
* **bordeaux-threads**: Portable multithreading library.
